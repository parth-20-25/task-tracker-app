# Design 2D Additional Tasks compatibility

New Design 2D work for Drafting through Wear-Out Data is created only through the fixture 2D Release Deliverables workflow.

Existing additional_design rows are retained unchanged and remain readable through task history and the direct Additional Tasks route. Creation remains available for unrelated Design 3D additional work. Open Design 2D records are not converted automatically because older rows do not guarantee a verified fixture mapping; they must be completed or cancelled through the legacy task history before equivalent release-deliverable work is assigned.
